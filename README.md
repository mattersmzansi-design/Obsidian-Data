# Squnga'esihle Trading — Stakeholder Portal

A single-page, self-contained stakeholder portal for **Squnga'esihle Trading (Pty) Ltd**,
a KwaZulu-Natal project management, social facilitation, and housing development enterprise.

## Contents

- **`index.html`** — the complete portal. No build step or dependencies; open it directly
  in a browser.

## Features

- **Live Portfolio Metrics** — switch between the Potshini Rural, Edendale Ext 18, and
  Amahlongwa PH3 projects to update units, facilitation status, and delivery stage.
- **Dynamic Methodology Timeline** — three social-facilitation phases (Stakeholder
  Introduction, PSC Committee, Social Compact) with click-to-reveal descriptions.
- **Statutory Registers & Enterprise Specifications** — CIDB / NHBRC verification modals
  plus company registration, B-BBEE, and CSD details.
- **Community Reels Series** — placeholder slots for KZN Community Voices video campaigns.
- **Stakeholder Appreciation Portal** — trackers for the Foundation Stone asset and
  handover celebration media.

## Notes

- The hero panel references a local image, `owner making presentation.jpg`. Drop that file
  next to `index.html` (or edit the `background-image` URL) to display it; a solid brand-sage
  colour shows as a fallback until then.
- All interactivity is vanilla JavaScript embedded in the page.
- The layout collapses to a single column below 900px wide for phones and tablets.
